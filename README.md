# 健康社交模擬遊戲｜單機版

可直接在瀏覽器遊玩的單人社交選擇遊戲，針對手機與電腦調整介面。

- 不需要登入、房號、後端或連線服務；首次開啟仍需下載網站檔案。
- 每局有 10 個隨機夜晚；每晚可從 5 種主要行動中選擇。
- 每桌先給一句短開場，再藏一條實質情報；花 3% 壓抑刺探一次就會翻開。若翻到人物界線，不相容行動會立刻鎖住，離開永遠可選。
- 高風險互動採延遲判決：結果不會立刻公布，會在醫院檢查或最終結算時揭曉。
- 遊戲會自動保存進度到此裝置的瀏覽器；重新整理或再次開啟時可繼續上一桌。
- 完成 10 個夜晚後，才會給出結局、完整復盤與已解鎖的人物故事；回合中不會先把整篇傳記講完。

## 本機預覽

```bash
python3 -m http.server 4173
```

開啟 `http://localhost:4173` 即可遊玩。

## 回歸檢查

```bash
npm run validate
```

這會檢查人物資料、刺探對話與界線鎖定、存檔恢復、100% 壓抑的提前結束、突發快轉時間軸、必要 DOM 節點與舊存檔內容的安全渲染。

## GitHub Pages

將 `main` 分支的根目錄設定為 GitHub Pages 的部署來源，即可由 GitHub 自動發佈靜態網站。
