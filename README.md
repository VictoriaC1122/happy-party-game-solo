# 健康社交模擬遊戲｜單機版

可直接在瀏覽器遊玩的單人社交選擇遊戲，針對手機與電腦調整介面。

- 不需要登入、房號、網路連線或伺服器。
- 每局有 10 個隨機夜晚；每晚可從 5 種主要行動中選擇。
- 可先聊天取得更多線索、使用試紙，或前往醫院提早揭曉目前結果。
- 高風險互動採延遲判決：結果不會立刻公布，會在醫院檢查或最終結算時揭曉。
- 遊戲會自動保存進度到此裝置的瀏覽器；重新整理或再次開啟時可繼續上一桌。
- 完成 10 個夜晚後，會給出結局、完整復盤與已解鎖的人物故事。

## 本機預覽

```bash
python3 -m http.server 4173
```

開啟 `http://localhost:4173` 即可遊玩。

## 回歸檢查

```bash
node --test tests/game-regression.test.js
```

這會檢查人物資料、存檔恢復、100% 壓抑的提前結束、突發快轉時間軸，以及舊存檔內容的安全渲染。

## GitHub Pages

將 `main` 分支的根目錄設定為 GitHub Pages 的部署來源，即可由 GitHub 自動發佈靜態網站。
