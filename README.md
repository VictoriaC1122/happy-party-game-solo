# 健康社交模擬遊戲｜單機版

以短標籤、一次刺探與延遲翻牌為核心的單人選擇遊戲，手機與電腦都可直接遊玩。

- 不需要登入、房號、後端或連線服務；首次開啟仍需下載網站檔案。
- 壓抑從 50 開始；壓抑歸零且最後翻牌未感染才過關。
- 每位對象有 3–4 個短標籤，最多藏 1 個；刺探花 3 點壓抑並經過一晚。
- 一張對方試紙不消耗晚數；醫院會經過一晚、壓抑 +10、壓力歸零。
- 四種親密行動與換人有不同數值；壓力超過 80 時，部分標籤會模糊。
- 感染不在行動後公布，只會在醫院或壓抑歸零時翻牌。
- 沒有固定晚數上限、生存分、突發事件或人物長故事。
- 遊戲會自動保存進度到此裝置的瀏覽器；重新整理或再次開啟時可繼續上一桌。

## 本機預覽

```bash
python3 -m http.server 4173
```

開啟 `http://localhost:4173` 即可遊玩。

## 回歸檢查

```bash
npm run validate
```

這會檢查 200 位人物與頭像、短標籤、刺探、試紙、醫院、五種行動、延遲判決、結局圖片、正式網址與玩家可見文案。

## GitHub Pages

將 `main` 分支的根目錄設定為 GitHub Pages 的部署來源，即可由 GitHub 自動發佈靜態網站。
