# 午夜選擇題｜單機版

可直接在瀏覽器遊玩的單人派對選擇遊戲，針對手機與電腦調整介面。

- 不需要登入、房號、網路連線或伺服器。
- 每局有 10 個隨機夜晚與 4 種選擇。
- 遊戲進度會暫存在裝置的瀏覽器；重新整理後可繼續。
- 完成 10 個夜晚後，會給出結局與完整的故事紀錄。

## 本機預覽

```bash
python3 -m http.server 4173
```

開啟 `http://localhost:4173` 即可遊玩。

## GitHub Pages

將 `main` 分支的根目錄設定為 GitHub Pages 的部署來源，即可由 GitHub 自動發佈靜態網站。
